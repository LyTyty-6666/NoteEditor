Frequently Asked Questions

Quick answers about NoteEditor features, safety, and compatibility.

Is NoteEditor really 100% free to download and use? +

Yes, absolutely. NoteEditor is 100% free with no trial periods, no hidden subscriptions, and no advertisements. You can use it freely for both personal and commercial projects.

Where are my notes and markdown files stored? +

All your files are saved locally on your computer in plain markdown (.md) or text (.txt) format. There are no proprietary lock-ins and no compulsory cloud servers. You retain 100% ownership and privacy of your data.

What version of Windows does NoteEditor require? +

NoteEditor is built for 64-bit Windows 11 and Windows 10. It also runs smoothly on Windows on ARM through native emulation.

Does NoteEditor support Math, Code Syntax, and Mermaid diagrams? +

Yes! It has full support for GitHub Flavored Markdown (GFM), math equations with LaTeX syntax, code syntax highlighting for over 50 languages, and interactive checklists.
